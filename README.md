# trip-ptb-metagenomics
Analysis code for 16S and short-read metagenomics datasets of TrIP vaginal and meconium samples

This repository contains the code used for the analysis reported in the manuscript: "Vaginal and meconium microbiomes associate with clinical subtypes of preterm birth".

Analyses cover 16S rRNA amplicon and short-read metagenomic datasets of vaginal and meconium samples from the TrIP (Tregs In Pregnancy) preterm birth cohort. All statistical analyses were performed in R v4.5.1.

.R files      – Functions used throughout the analysis

.Rmd files    – Split by data type (16S vs MGS), sample type (LVS vs MEC) and taxonomic vs functional analyses

Data availability
Raw sequencing data — NCBI SRA, BioProject PRJNA1517970
Sample metadata — Supplementary Data S1 of the associated publication
Parameters for raw data processing are given in the Methods section of the manuscript
